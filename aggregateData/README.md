# aggregateData Directory

This directory is the local data workspace for the PCA sentiment analysis
section.

## Required Local Files

- `TS.xlsx`
  Input dataset used by `code/Get_PCAMS.py`.
- `TS_CSI_300_PCA.xlsx`
  PCA and regression dataset for the CSI 300 sample.
- `TS_CSI_ALL_PCA.xlsx`
  PCA and regression dataset for the CSI All Share sample.

These Excel files are not tracked in the public repository because of copyright
and data licensing restrictions. Place them in this directory when reproducing
the analysis locally.

## Tracked Outputs

- `*.csv`
  Publicly shareable exported result summaries.
- `*.png`
  Publicly shareable figures.

## Not Tracked By Default

- `*.xlsx`
  Restricted local datasets and intermediate workbooks.
- `*.docx`
  Word tables generated by the regression and mediation scripts.
