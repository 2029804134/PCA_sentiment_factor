# Open-Source Release Checklist

Before making this trimmed repository public, check the following:

1. Confirm that `TS.xlsx`, `TS_CSI_300_PCA.xlsx`, and `TS_CSI_ALL_PCA.xlsx` can be redistributed.
2. Confirm that no personal thesis drafts or defense materials remain tracked.
3. Confirm that the repository only contains the six analysis scripts plus the small workflow entry point.
4. Confirm that generated Word outputs are still ignored unless you intentionally want to publish them.
5. Update the copyright holder line in `LICENSE` if you want your own name displayed.
